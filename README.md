Repositório dedicado ao desenvolvimento de aplicações web interativas, jogos arcade de alta performance e experiências visuais imersivas. Este espaço complementa minha stack de engenharia frontend, focando em renderização otimizada (60 FPS), física 2D customizada e design de interfaces responsivas.

---

## 🎯 Objetivo do Repositório
Demonstrar competência técnica prática no desenvolvimento full-stack frontend: desde a implementação de loops de animação síncronos e tratamento de física com detecção de colisão AABB até a criação de Design Systems modernos em dark-mode e deploy contínuo em páginas estáticas.

---

## 🏗️ Arquitetura & Padrões de Projeto
- **Isolamento Total:** Cada projeto está contido em sua própria pasta com dependências, configurações e builds independentes, garantindo que nada se misture.
- **Zero Friction:** Projetos desenhados para rodar imediatamente com build estático leve, otimizados para deploy direto em ambientes como GitHub Pages.
- **Modularidade & Tipagem:** Código fortemente tipado em TypeScript, com separação estrita entre a camada de interface (React/Tailwind) e o motor gráfico (HTML5 Canvas).

---

## 🛠️ Stack Tecnológica Geral
- **Core:** React 18+, TypeScript
- **Estilização & UI:** Tailwind CSS (Dark-Mode Arcade Theme)
- **Gráficos & Física:** HTML5 Canvas API (`requestAnimationFrame`), 2D Vector Physics
- **Build & Tools:** Vite, Node.js
